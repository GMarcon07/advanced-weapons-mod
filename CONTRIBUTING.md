# Contribuindo para Advanced Firearms Mod

Obrigado por seu interesse em contribuir! Este documento fornece diretrizes para contribuir.

## Como Contribuir

### Reportando Bugs

1. Use o [GitHub Issues](https://github.com/GMarcon07/advanced-weapons-mod/issues)
2. Descreva o bug em detalhes
3. Forneça passos para reproduzir
4. Mencione sua versão do Minecraft e Fabric

### Sugerindo Features

1. Verifique se a sugestão já existe
2. Abra uma issue com o título "Feature: [descrição]"
3. Descreva a funcionalidade desejada
4. Explique o caso de uso

### Pull Requests

1. Fork o repositório
2. Crie uma branch (`git checkout -b feature/AmazingFeature`)
3. Commit suas mudanças (`git commit -m 'Add AmazingFeature'`)
4. Push para a branch (`git push origin feature/AmazingFeature`)
5. Abra um Pull Request

## Padrões de Código

- Use Kotlin para novas classes
- Siga as convenções de nomenclatura Kotlin
- Adicione comentários para lógica complexa
- Mantenha as funções curtas e focadas

## Estrutura de Branches

- `main` - Versão estável
- `firearms-weapons` - Branch de desenvolvimento
- `feature/*` - Novas features
- `bugfix/*` - Correções de bugs
