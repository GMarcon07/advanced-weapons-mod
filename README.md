# Advanced Weapons Mod

Um mod Fabric para Minecraft 1.21.1 que adiciona 5 armas customizadas inspiradas em TACZ, com sons, texturas e efeitos especiais únicos para cada arma.

## 🎮 Armas Disponíveis

### 1. **Espada de Plasma** ⚡
- **Dano**: 11.0 total (+8.0 adicional)
- **Velocidade**: -2.4
- **Efeito**: Aplica brilho (Glowing) ao inimigo
- **Partículas**: Centelhas elétricas azuis

### 2. **Cimitarra Negra** 🗡️
- **Dano**: 9.0 total (+6.0 adicional)
- **Velocidade**: -1.8
- **Efeito**: Concede velocidade aumentada ao atacar
- **Partículas**: Centelhas roxas

### 3. **Machado de Guerra** 🪓
- **Dano**: 13.0 total (+10.0 adicional)
- **Velocidade**: -3.1
- **Efeito**: Knockback aumentado
- **Partículas**: Fumaça cinzenta

### 4. **Lâmina Congelante** ❄️
- **Dano**: 10.0 total (+7.0 adicional)
- **Velocidade**: -2.0
- **Efeito**: Congela inimigos (Slowness + Weakness)
- **Partículas**: Flocos de neve

### 5. **Gume Demoníaco** 😈
- **Dano**: 12.0 total (+9.0 adicional)
- **Velocidade**: -2.8
- **Efeito**: Weakness ao inimigo, Strength ao jogador
- **Partículas**: Fumaça vermelha/roxa

## 📋 Requisitos

- Minecraft 1.21.1
- Fabric Loader 0.15.11+
- Fabric API

## 🚀 Instalação

1. Certifique-se de ter o Fabric Loader instalado
2. Copie o arquivo `.jar` para a pasta `mods`
3. Reinicie o Minecraft

## 🛠️ Compilação

```bash
./gradlew build
```

## 📁 Estrutura

- `src/main/kotlin/` - Código-fonte em Kotlin
- `src/main/resources/` - Assets (texturas, sons, modelos, idiomas)
