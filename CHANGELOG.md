# Changelog - Advanced Firearms Mod

## [1.0.0] - Firearms Release (2026-08-31)

### ✨ Adicionado
- Adicionadas 5 armas de fogo customizadas:
  - **M4A1 Rifle de Assalto** - Versatilidade balanceada
  - **Pistola 9mm** - Rápida e compacta
  - **Shotgun Combat** - Poderosa para close-range
  - **Rifle AWM (Sniper)** - Precisão letal
  - **Subfusil MP5** - Cadência de tiro máxima

- Sistema de sons completo:
  - Sons de disparo para cada arma
  - Sons de recarga
  - Sons de impacto em carne e blocos
  - Sons de ricochete

- Sistema de efeitos:
  - Partículas de disparo
  - Dano customizado por arma
  - Knockback dinâmico
  - Status effects especiais:
    - AWM: Cegueira ao inimigo
    - MP5: Slowness (lentidão)
    - Shotgun: Knockback massivo

- Suporte multilíngue:
  - Português Brasileiro (PT-BR)
  - Inglês Americano (EN-US)

- Integração visual:
  - Texturas personalizadas para todas as armas
  - Modelos customizados
  - Tooltips com informações de dano e cadência
  - Ícone do mod personalizado

### 🎮 Mecânicas
- Clique direito para apontar
- Clique esquerdo para disparar
- Sem limite de munição (versão 1.0)
- Dano por disparo:
  - M4A1: 8.0
  - Pistola: 6.0
  - Shotgun: 12.0
  - AWM: 15.0
  - MP5: 5.0

### 📊 Cadência de Tiro
- M4A1: 3 tiros/segundo
- Pistola: 4 tiros/segundo
- Shotgun: 1 tiro/segundo
- AWM: 0 tiros/segundo (bolt-action)
- MP5: 6 tiros/segundo (mais rápida)

### 🔍 Precisão
- M4A1: 80%
- Pistola: 60%
- Shotgun: 50%
- AWM: 100%
- MP5: 70%

### 🏗️ Técnico
- Código em Kotlin com Fabric API
- Mixins para efeitos cliente-side
- Sistema de registry customizado
- Estrutura extensível para futuras armas
