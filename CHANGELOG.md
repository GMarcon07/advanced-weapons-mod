# Changelog

## [1.0.0] - 2026-08-31

### Added
- Adicionadas 5 armas customizadas:
  - Espada de Plasma ⚡
  - Cimitarra Negra 🗡️
  - Machado de Guerra 🪓
  - Lâmina Congelante ❄️
  - Gume Demoníaco 😈
- Sistema de efeitos de partículas para cada arma
- Status effects especiais por arma
- Sons customizados (ataque e impacto)
- Texturas personalizadas
- Suporte a português e inglês
- Integração completa com Fabric API

### Features
- Cada arma possui dano, velocidade e efeitos únicos
- Efeitos visuais ao atacar inimigos
- Dano adicional customizado
- Knockback ajustado
- Duração de efeitos variada por arma
